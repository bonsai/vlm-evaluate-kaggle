# VLM Evaluate Kaggle

A separate evaluation workspace for image pairs generated by `bonsai/comfy-gen-lora`.

## Responsibility split

- **Image generation:** `bonsai/comfy-gen-lora`
- **Image-pair dataset:** a Kaggle Dataset containing generated images and `manifest.jsonl`
- **VLM evaluation loop:** this repository / Kaggle Notebook
- **Evaluation outputs:** JSONL records keyed by `experiment_id`

This repository is intentionally independent from the generation notebook so the same images can be evaluated repeatedly with different VLMs without regenerating them.

## Dataset contract

Expected dataset layout:

```text
dataset/
├── manifest.jsonl
└── images/
    ├── exp-0001_lora.png
    └── exp-0001_baseline.png
```

One JSON object per line in `manifest.jsonl`:

```json
{
  "experiment_id": "exp-0001",
  "prompt_id": "woman-snake-pc-v1",
  "seed": 42,
  "lora_image": "images/exp-0001_lora.png",
  "baseline_image": "images/exp-0001_baseline.png",
  "resolution": "768x768",
  "evaluation_status": "pending"
}
```

Paths are relative to the dataset root. Preserve the experiment ID and generation metadata when adding pairs.

## Evaluation targets

For each image, assess:
1. Woman present: present / partial / absent / uncertain
2. Snake present: present / partial / absent / uncertain
3. PC (monitor and/or keyboard) present: present / partial / absent / uncertain
4. All three visible together
5. Observable style and image-quality differences
6. Uncertainty; do not infer details that are not visible

Compare LoRA and baseline images, but do not claim a causal LoRA effect from a single image pair. Use repeated seeds/prompts for stronger evidence.

## Execution

1. Create or attach the Kaggle Dataset with image pairs and `manifest.jsonl`.
2. Open `vlm_evaluate.ipynb` in Kaggle.
3. Configure the dataset input path.
4. Choose local VLM inference (model downloaded in Kaggle) or implement a cloud provider adapter using Kaggle Secrets.
5. Run the evaluation loop. Results are appended to `evaluations/results.jsonl`; completed experiment IDs are skipped on rerun.

No API keys or tokens belong in notebook source. Local model inference in Kaggle runs on the Kaggle VM; it does not connect to LM Studio on your personal computer via `localhost`.
